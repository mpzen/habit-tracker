# Habit Tracker

A tiny, no-framework habit tracker. Add habits, check them off each day, watch your streak grow.

Built step by step as a hands-on way to learn Git, GitHub, and Claude Code — one branch and one pull request per feature.

## Running it

No build step. Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Project layout

| File | Purpose |
|------|---------|
| `index.html` | Page structure |
| `styles.css` | All styling |
| `app.js` | App logic |
